# Security Policy

## Reporting a Vulnerability

Please **do not open public issues** for suspected vulnerabilities.

Report vulnerabilities privately using GitHub Private Vulnerability Reporting:

- <https://github.com/gromer/openclaw-pi/security/advisories/new>

Include:

- Affected versions/commit SHA
- Reproduction steps or proof-of-concept
- Impact and attack preconditions
- Suggested mitigation (if known)

If you accidentally disclose secrets while reporting, rotate them immediately and
note the rotation in your report.

## Supported Versions

Security fixes are provided for:

| Version | Supported |
| --- | --- |
| `main` branch (unreleased development) | ✅ |
| Latest published release tag | ✅ |
| Older release tags | ❌ |

## Disclosure Expectations

- We aim to acknowledge private reports within **3 business days**.
- We aim to provide an initial triage decision within **7 business days**.
- For confirmed issues, we target a fix or mitigation plan within **30 days**,
  based on severity and operational risk.
- Please wait for a coordinated disclosure date before publishing details.
